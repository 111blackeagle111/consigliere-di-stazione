# Contribuire al progetto

Grazie per il tuo interesse a contribuire a questo progetto! Di seguito le linee guida principali per aprire issue e PR.

1. Aprire un'issue prima di lavorare su una nuova caratteristica importante: descrivi lo scopo, i passi per riprodurre (se bug) e il comportamento atteso.
2. Prima di inviare una Pull Request:
   - Forka il repository e crea un branch con nome descrittivo (es. `feat/inferenza-offline`, `fix/ui-bug`).
   - Esegui i test locali (se presenti) e assicurati che il codice segua lo stile del progetto.
   - Includi una descrizione chiara della PR nel template fornito.
3. Stile e qualità:
   - Python: usa formattazione automatica (es. black/ruff) se possibile.
   - Scrivi commit descrittivi e atomici.
4. Tests e CI:
   - Aggiungi test per nuove funzionalità quando possibile.
5. Review:
   - Le PR saranno revisionate; rispondi ai commenti e aggiorna il codice secondo i suggerimenti.

Se hai dubbi, apri un'issue e discutiamone prima di investire tempo nello sviluppo.
